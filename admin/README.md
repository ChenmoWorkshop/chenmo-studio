# 创作工坊 · 管理后台（chenmo-admin）

与用户端（根目录 `index.html`）**完全分离**的云端管理后台：Vue 3 + Vite 构建，通过 HTTP 调用同一个云函数 `chenmo-api` 的 `admin*` 动作读写 CloudBase 数据库。

## 与前方案的关系

```
用户浏览器 ── fetch ──> 云函数 chenmo-api ──> CloudBase 数据库
管理后台  ── fetch ──> 同一函数（admin* 动作）──┘
```

两端共用一套数据库，但**鉴权体系完全隔离**：用户用账号密码，管理员用独立密钥。

## 登录

管理入口页要求输入「管理员密钥」，即云函数环境变量 `ADMIN_KEY`。

- 密钥**不写在任何仓库文件里**，只存在云端环境变量
- 登录换取令牌，**8 小时**后自动失效（用户 token 是 90 天）
- 未配置 `ADMIN_KEY` 时所有管理动作一律拒绝（fail-closed）

## 功能

| 模块 | 能力 |
|---|---|
| 数据总览 | 注册用户/绑邮箱/停用/内容总量四个指标；近 7 天注册趋势；四模块内容分布；账号内容量排行 |
| 用户管理 | 关键字搜索、查看详情、**封禁/解封**、**重置密码**、**强制下线**、解绑邮箱、**删除账号** |
| 用户详情 | 按待办/灵感/内容进度/复盘四个 Tab 查看该账号的真实数据明细 |
| 运维工具 | 扫描与清理过期会话、过期验证码；一键登出全部管理员会话 |

危险操作均有二次确认：删号需手动输入账号名；重置密码会同时吊销该账号全部会话。

## 本地开发

```bash
cd admin
npm install --ignore-scripts      # 沙箱环境下避免 esbuild postinstall 报错
npm run dev                        # http://127.0.0.1:5273
```

> ⚠️ 注意：本地开发时访问 `127.0.0.1` 会被云端 CORS 拦截（云端只放行 `*.app.workbuddy.host`）。
> 调试真实数据请用 Playwright 在 Node 侧转发请求，或部署后再联调。

## 构建与部署

```bash
npm run build          # 产物在 admin/dist
```

部署时把 `admin/dist` 作为静态站点发布即可（与用户端是两个独立站点，互不影响）。

## 安全约定

- 管理员令牌与普通用户账号**互不影响**：即使某个用户被提升权限也进不了后台
- 每次管理操作都重新校验令牌，令牌失效即刻清出
- 用户文档离开服务端前统一脱敏（`adminUserView`），不含密码哈希与盐
- 删除账号会连带清除其会话、全部业务数据与微信绑定关系
