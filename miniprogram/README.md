# 创作工坊 · 微信小程序（界面演示版）

这是「创作工坊」手机端的小程序版本，当前处于**界面演示阶段**：所有页面、交互、视觉都与手机网页版一致，数据用的是本地示例数据 + 本地缓存，**尚未接入云函数**。

## 怎么打开看效果

1. 安装「微信开发者工具」（官方下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html）
2. 打开工具 → 「导入项目」→ 目录选择本文件夹（`miniprogram`）
3. AppID 选择「**测试号**」或直接使用游客模式（`project.config.json` 里已填 `touristappid`）
4. 编译即可看到效果；登录页 →「微信一键登录」→ 输一次账号密码完成绑定 → 进入工作台

> 用测试号不影响界面预览；等正式注册了小程序、拿到 AppID，把 `project.config.json` 里的 `appid` 换成真实 AppID 即可。

## 已经完成的页面

| 页面 | 内容 |
|---|---|
| 登录 / 绑定 | 微信一键登录（首次引导绑定已有账号）、账号密码登录、游客体验 |
| 工作台 | 顶部通栏（头像 + 工作台名 + 每日名言，可点击换一条）、问候语、今日重点（快捷添加 + 优先级选择 + 筛选 + 分页）、内容进度概览 |
| 灵感 | 记一条灵感（内容 + 分类）、分类筛选、列表分页 |
| 进度 | 全部 / 想法 / 制作中 / 已发布筛选，卡片轻触改名、长按切换状态或删除，新建内容 |
| 日历 | 月历（周一为起点、固定 6 行 42 格）、当天高亮、事件条按状态着色、本月计划清单 |
| 复盘 | 四项填写 + 保存 + 历史记录分页，长按删除 |
| 资料 | 更换头像、改工作台名称与副标题、查看账号与绑定状态、退出登录 |

## 与网页版的关系

- 配色、字体层级、圆角与间距全部沿用网页版的设计变量（`app.wxss` 顶部集中定义，改一处全局生效）
- 数据结构完全一致：`todos / ideas / contents / reviews` 四个集合，字段名与云端相同（见 `mock/data.js`）
- 每日名言规则一致：每天 10 条、两个池交替、按时段自动轮换、点击切换、点满 10 次回到起点（`utils/quote.js`）

## 下一步（接入云端时要做的事）

1. 在小程序后台开通云开发，把腾讯云侧已有的 CloudBase 环境关联进来（微信开发者工具 → 设置 → 环境设置 → 管理我的环境 → 使用已有腾讯云环境）
2. `app.js` 里 `wx.cloud.init({ env: '现有环境ID' })`
3. 把 `db()` / `save()` 从本地缓存改为 `wx.cloud.callFunction`
4. 云函数新增 `wxLogin`（用 `cloud.getWXContext().OPENID` 换登录态）与 `bindWx`（把 openid 绑到已有账号）
5. 详情见项目根目录的 `.workbuddy/docs/小程序接入方案.md`
